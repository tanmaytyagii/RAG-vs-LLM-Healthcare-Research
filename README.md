# Evaluating RAG and LLM Architectures for Evidence-Grounded Healthcare AI

## 📌 Overview
This research explores the comparison between Retrieval-Augmented Generation (RAG) and Large Language Models (LLMs) in healthcare AI systems.

## 🎯 Objectives
- Analyze hallucination issues in LLMs
- Compare factual accuracy of RAG vs LLM
- Evaluate clinical reliability and safety

## 🔍 Key Findings
- RAG significantly reduces hallucinations
- Improves factual correctness in medical responses
- Provides better evidence-grounded outputs
